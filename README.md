# DOME LIVE — スタッフ用

スタッフ確認・サイネージ投影のための進行サイト。

URLを開き、スタッフ共通のパスワードを入力すると進行画面・マニュアルを表示します。パスワードはリポジトリに記載していません。

## 表示

- 日本時間に合わせて自動進行。開始操作は不要。
- DAY1 / DAY2、サイネージ、リハーサル時刻に対応。
- 開催年は仮に2026年。設定で確認してください。
- 担当表・マニュアルはロック解除後に表示。
- スタッフメニューのロックで内容を閉じます。

## オフライン

初回はネット接続が必要です。「オフライン保存済み」の表示後は、同じブラウザ・同じURLからオフラインでもパスワードで開けます。ブラウザが保存データを削除した場合は再接続が必要です。オフライン中は更新を取得できないため、開催直前にオンラインで開いてください。

## 保護方式

進行画面とマニュアルはAES-256-GCMで暗号化し、鍵はPBKDF2-SHA256（600,000回）でパスワードから導出します。リポジトリには画面の元データ・パスワード・復号鍵を保存していません。

共通パスワード方式のため、個人別のアカウント管理や閲覧記録はありません。パスワードを知る人は内容を読めます。

## 配信

GitHub Pagesでmainブランチのルートを公開します。外部ライブラリやビルドは不要です。元PDF・Excelは含めていません。
