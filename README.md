# Linc_03.zip

- `index.html`：客用の進行画面（パスワード不要）。
- `staff.html`：スタッフ共通パスワードで進行画面・担当表・マニュアルを表示。
- `signage02.html`：ライブ映像、現在と次の演目、残り時間、Instagram QR。

企画・出演者・時間は全体タイテのExcelを正としています。通常DJ枠は番号でなく出演者名を表示。Excelで未定の枠は未定と表示します。

## ライブ表示

サイネージ02の「ライブ設定」にYouTube Live、Twitchチャンネル、HTTPSのMP4/WebMのURLを入力。映像はネット接続が必要です。ブラウザごとに保存し、URL共有にも対応します。実際の配信URLは未設定です。配信側の埋め込み許可が必要です。配信映像の遅延と進行時計は同期しません。

## オフライン

初回のオンライン読み込み後に画面と進行データを保存します。ライブ映像自体は保存せず、ネット接続が必要です。ブラウザが保存データを削除した場合は再接続してください。開催直前にオンラインで開いて最新版を取得してください。

## スタッフページ

担当表・マニュアルの本文はAES-256-GCMで暗号化。鍵はPBKDF2-SHA256（600,000回）で共通パスワードから導出します。パスワードや鍵はリポジトリに保存しません。個人別のアカウント管理・閲覧記録はありません。

GitHub Pagesでmainブランチのルートを公開します。元のPDF・Excelは含めていません。
